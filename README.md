# kommunalservice-web

Website und Lead-Engine für zulassungsfreie kommunale Routine-, Erfassungs- und Dokumentationsdienstleistungen.

## Status

Erste strategische und technische Website-Fassung. **„Kommunalservice“ ist aktuell nur ein Arbeitstitel** und bewusst zentral gehalten, damit Markenname und Domain später ohne strukturellen Umbau ersetzt werden können.

## Positionierung

Die Website verkauft keine Sachverständigen-, Bewachungs- oder hoheitlichen Leistungen. Kern sind klar abgegrenzte Routineleistungen, bei denen die Kommune Kriterien vorgibt und fachliche Entscheidungen selbst behält.

Aktuelle Kernmodule:

- Starkregen-Bereitschaftscheck
- Lichtraum- und Überwuchserfassung
- Mängelmelder-Backoffice
- Notfalltreffpunkt-Inventur
- Aufbruch-Fotodokumentation
- kombinierte kommunale Rundgänge

## Entwicklung

```bash
npm install
npm run dev
```

Für einen Produktionsbuild:

```bash
npm run build
npm run start
```

## Vor Veröffentlichung noch erforderlich

- finaler Markenname und Domain
- echte Kontaktadresse statt `kontakt@example.de`
- Impressum mit finalen Unternehmensdaten
- Datenschutzerklärung / AVV-Konzept für Backoffice-Leistungen
- Hosting- und Formularentscheidung
- finale juristische Prüfung der Leistungsbeschreibungen
- Ergänzung weiterer SEO-/Kommunalwissen-Seiten auf Basis der Marktrecherche
